# План разработки Release 1.1: Production Polish, UX & Shared Storage

Архитектурный и инженерный план масштабного релиза 1.1 для Omega Cloud. Разбит на 4 независимых этапа реализации — от низкоуровневых доменных моделей и безопасности до UX десктопного уровня, локализации и финального полишинга.

---

## Архитектурные решения (согласованные в ходе /grill-me)

1. **Общий раздел (Shared Space):**
   - Реализуется через флаг `IsShared` у сущностей `Folder` и `FileItem`.
   - Загруженный в Shared Space файл списывает объем с личной квоты автора (`UserId`).
   - Права на мутацию (переименование, перемещение, удаление): только автор (`UserId == CurrentUserId`) или администратор системы (`UserRole.Admin`).
2. **Анонимный доступ (Read-Only):**
   - Публичный маршрут в SPA: `/shared` (доступен без аутентификации).
   - Read-Only эндпоинты бэкенда `/api/v1/shared/**` с атрибутом `[AllowAnonymous]`, отдающие дерево папок и стриминг скачивания без JWT-токена.
3. **Разрешение коллизий имен (Upload Collision Engine):**
   - Клиентский pre-flight анализ перед стартом загрузки.
   - Диалог при совпадении имен: «Заменить» (`Replace`), «Сохранить оба» (`Rename` с суффиксом `_(1)`), «Пропустить» (`Skip`) + чекбокс «Применить ко всем конфликтам».
   - Поддержка параметров разрешения коллизий в API загрузки (`ConflictResolutionStrategy`).
4. **Таргетинг нод и лимиты:**
   - Поле `MaxCapacityBytes` в сущности `StorageNode`, настраиваемое в админ-панели.
   - Жесткая валидация: суммарная выделенная квота пользователей не может превышать сумму доступных емкостей активных нод (`sum(AllocatedQuotaBytes) <= sum(ActiveNodes.MaxCapacityBytes)`).
   - Автоматическая балансировка загрузки на наименее заполненную ноду.

## Этап 1. Доменные модели, безопасность, квоты и ноды (Backend Core)
> **Цель этапа:** Подготовить фундамент базы данных, вычистить устаревшие роли, обеспечить строгую безопасность сессий и физический учет емкости хранилища.

### Задачи:
1. **Удаление роли `Guest`:**
   - Удалить `Guest` из перечисления `UserRole` (`OmegaCloud.Domain.Enums.UserRole`).
   - Создать и применить миграцию EF Core (конвертация существующих записей с ролью Guest в User при наличии).
   - Очистить упоминания роли Guest в проверках авторизации, сервисах и сидерах.
2. **Инвалидация сессий и токенов (Session Security Fix):**
   - Добавить проверку `UserSession.RevokedAt` при валидации JWT (через `OnTokenValidated` в `JwtBearerEvents` или быстрый кэш отозванных сессий).
   - При вызове `RevokeSessionAsync`:
     - Обновлять `RevokedAt` в базе данных.
     - Принудительно разрывать SignalR-соединение отозванной сессии (`OmegaHub` disconnect/abort).
     - Блокировать дальнейшие запросы с токеном данной сессии с возвратом HTTP 401.
3. **Лимиты емкости нод и валидация квот:**
   - Добавить поле `MaxCapacityBytes` в сущность `StorageNode` (и DTO админки).
   - Внедрить валидацию в `AdminUserService`: запретить создание/изменение пользователя с квотой `AllocatedQuotaBytes`, если общая сумма квот превысит суммарную емкость активных нод.
   - В `NodeService` добавить возможность изменения `MaxCapacityBytes` для каждой ноды через админку.
   - Обновить стратегию выбора ноды по умолчанию при загрузке: выбирать активную ноду с максимальным свободным объемом (`MaxCapacityBytes - UsedBytes`).
4. **Доменные сущности Shared Space:**
   - Добавить свойство `public bool IsShared { get; set; } = false;` в `Folder` и `FileItem`.
   - Добавить индексы в EF Core конфигурации для быстрой выборки `IsShared` объектов.
   - Создать миграцию базы данных `AddSharedSpaceAndNodeCapacity`.

## Этап 2. Сервисы Shared Space, коллизии и превью (Backend API & Services)
> **Цель этапа:** Реализовать публичные и защищенные API эндпоинты для общего доступа, алгоритмы разрешения конфликтов файлов и серверный генератор превью.

### Задачи:
1. **API Общего раздела (Shared Space):**
   - Создать `ISharedService` и `SharedService` в `OmegaCloud.Application`.
   - Создать контроллер `SharedController` (`/api/v1/shared`):
     - `GET /api/v1/shared/folders` (дерево/содержимое папок, `[AllowAnonymous]`).
     - `GET /api/v1/shared/files/{id}/metadata` (`[AllowAnonymous]`).
     - `GET /api/v1/shared/files/{id}/download` (скачивание файла, `[AllowAnonymous]`).
     - `POST /api/v1/shared/upload` (загрузка в общий раздел, требует авторизации `[Authorize]`, списывает личную квоту автора).
     - `DELETE /api/v1/shared/files/{id}` и `DELETE /api/v1/shared/folders/{id}` (проверка прав: только автор или Admin).
2. **Обработка коллизий имен файлов:**
   - Добавить эндпоинт предварительной проверки `POST /api/v1/files/check-conflicts` (принимает список имен и `folderId`, возвращает массив существующих дубликатов).
   - Ввести перечисление `ConflictResolutionStrategy` (`Replace`, `Rename`, `Skip`).
   - Расширить `FileService` и `UploadService`:
     - Режим `Replace`: замещение содержимого (обновление ссылки на `StorageBlob`, пересчет квоты автора на разницу в байтах).
     - Режим `Rename`: безопасная автогенерация имени с уникальным постфиксом `filename (N).ext`.
     - Режим `Skip`: возврат существующего файла без повторной записи.
3. **Генерация и отдача превью (Thumbnails & Previews):**
   - Добавить эндпоинт `GET /api/v1/files/{id}/thumbnail` и превью для картинок/документов.
   - Легковесный ресайз изображений (JPEG/WebP) с кэшированием на сервере.
   - Поддержка стриминга аудио и видео (HTTP 206 Partial Content / Range header).
4. **Метрика Last Active At:**
   - Обновлять `UserSession.LastActiveAt` и `User.UpdatedAt` при активности.
   - Добавить поле `LastActiveAt` в DTO пользователя для отображения в таблице пользователей админ-панели.

## Этап 3. Десктопный UX, D&D, мультивыделение и модальные окна (Frontend Core)
> **Цель этапа:** Превратить веб-интерфейс в полноценный настольный проводник файлов, устранив баги модалок, жестов и выделения.

### Задачи:
1. **Фикс модальных окон (Backdrop Click Bug):**
   - В `glass-modal.component.ts`: добавить раздельное отслеживание `mousedown` и `mouseup`.
   - Инициировать закрытие окна только тогда, когда оба события произошли строго на элементе `.modal-backdrop`. Если `mousedown` был внутри контента модалки — закрытие блокируется.
2. **Desktop-style поведение кликов и мультивыделение:**
   - Одиночный клик: выделение карточки/строки (без мгновенного открытия боковой панели свойств).
   - Двойной клик (`dblclick`): открытие папки или вызов превью файла.
   - `Ctrl / Cmd + клик`: добавление/удаление элемента из множественного выбора.
   - `Shift + клик`: диапазонное выделение группы файлов между опорным и текущим элементом.
   - Резиновая рамка выделения (Marquee / Drag-to-select) на пустом пространстве сетки файлов.
   - Панель групповых действий (Bulk Action Bar): скачивание пачки в zip, массовое удаление, перемещение.
3. **Десктопный Drag-and-Drop (D&D):**
   - На десктопе: реализовать нативные события `dragstart`, `dragover`, `dragleave`, `drop` для перемещения файлов в папки.
   - Сохранить и изолировать сенсорные touch-события для мобильных устройств.
   - Визуальная индикация цели сброса (hover glow на папке-приемнике).
4. **Контекстное меню рабочего поля:**
   - Обработка клика правой кнопкой мыши (`contextmenu`) по пустой рабочей области: пункты «Создать папку», «Загрузить файлы», «Обновить», «Свойства папки».
5. **Навигация в браузере (History API):**
   - Привязать навигацию по папкам к роуту (`/drive?folder={id}` или `/drive/folder/{id}`).
   - Поддержать корректную работу кнопок браузера «Назад» и «Вперед» без перезагрузки и без выхода из диска.
6. **Уведомления (Toast Notifications Fix):**
   - Исправить логику кнопки «Очистить все» в сервисе уведомлений (гарантированное удаление всех активных toast-сообщений).

## Этап 4. Загрузка, Shared UI, Дашборд, i18n и финальный полишинг (Experience & Release)
> **Цель этапа:** Реализовать диалоги загрузки, интерфейс общего раздела, главную страницу, многоязычность и подготовить проект к релизу.

### Задачи:
1. **Продвинутый диалог загрузки папок и коллизий:**
   - Модальное окно очереди загрузки при drop папки или группы файлов: фильтрация файлов, превью очереди, расчет суммарного объема.
   - Модальное окно коллизий при обнаружении совпадений имен: выбор («Заменить», «Сохранить оба», «Пропустить») + чекбокс «Применить ко всем конфликтам».
2. **Интерфейс Общего раздела (Shared Space UI):**
   - Публичная страница `/shared`:
     - Для неавторизованных пользователей: чистый интерфейс только для чтения, просмотр файлов/папок и прямое скачивание.
     - Для авторизованных пользователей: дополнительная возможность перетаскивания и загрузки файлов, индикация владельца каждого файла/папки, кнопки удаления для своих файлов.
   - Добавить пункт «Общий раздел» в боковое меню приложения.
3. **Главная страница (Dashboard):**
   - Новый компонент и роут `/dashboard` (добавить в сайдбар):
     - Виджет «Недавние файлы» (последние загруженные/измененные).
     - Виджет «Статус хранилища» (диаграмма занятого места, лимит квоты).
     - Панель быстрых действий («Загрузить файл», «Создать папку», «Перейти в Общий раздел»).
4. **Многоязычность (i18n):**
   - Внедрить сервис локализации с поддержкой трех языков: Русский (RU), Английский (EN), Китайский (ZH).
   - Словари переводов для UI-элементов, сообщений об ошибках, кнопок и меню.
   - Переключатель языка в шапке / настройках профиля с сохранением в `localStorage`.
5. **Расширенный поиск:**
   - Дропдаун области поиска: «Везде» vs «В текущей папке и подпапках».
   - Фильтрация результатов по выбранной области.
6. **Production Polish:**
   - Убрать предзаполненные тестовые логин (`admin`) и пароль (`Admin123!`) на странице входа.
   - Мобильная адаптация: минимальный размер touch-target 44px, скрываемый drawer сайдбара, нижняя шторка действий (Action Sheet).
   - Заменить дефолтный фавикон на фирменный `favicon.ico` и `favicon.png` Omega Cloud.
   - Создать исчерпывающий `README.md` со структурой проекта, схемой архитектуры, docker-compose командами и переменными окружения.

## Чеклист верификации релиза

| Модуль | Критерий успешности |
|---|---|
| **Сессии** | При нажатии «Завершить сессию» в профиле токен перестает работать (401), а SignalR сокет разрывается немедленно. |
| **Квоты** | Нельзя создать пользователя с квотой больше, чем сумма `MaxCapacityBytes` всех доступных нод. |
| **Коллизии** | Загрузка существующего файла открывает диалог, «Сохранить оба» сохраняет файл как `name (1).ext`. |
| **Shared Space** | Неавторизованный пользователь может скачать файл по ссылке `/shared`, но не может загружать или удалять. |
| **Модалки** | Выделение текста в инпуте с отпусканием курсора за пределами окна больше не закрывает модалку. |
| **Выделение** | `Ctrl+клик` и рамка выделяют пачку файлов, тулбар действий работает с выбранными элементами. |
| **i18n** | Переключение на ZH или EN мгновенно переводит интерфейс и сохраняет выбор после обновления страницы. |
